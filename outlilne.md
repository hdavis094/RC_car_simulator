Project idea - Donkey Car Simulator 

What: this will be a desktop application. So it will not be deployed.

Purpose: The purpose of this project is to design and test components on rc cars and test the code before trying it on the actual hardware.

-3 Environments
	1. Workbench: choose the components and sensors to use on your car
	2. Terminal: build your code
	3. 3D World: built around a track. User can add and remove items that the vehicle will have to go navigate around. The user should also be able to use terminal while in the 3D world if they are operating the vehicle over a network.
	
The first iteration: One car wired to work the controller is an esp32
